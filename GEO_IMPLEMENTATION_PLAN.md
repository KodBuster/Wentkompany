# План правок после одобрения

Код в этом проходе не менялся. Ниже только то, что можно сделать после «да» по строке. URL и schema не двигать.

Приоритет: P0 ломает доверие к факту, P1 мешает точному ответу, P2 косметика смысла.

Оценка усилия: S до часа, M полдня. Риск: низкий, если не добавлять новые характеристики.

## P0

### 1. Плитка «0 переделок»

- URL: `/`
- Файл: `src/components/home-page-content.tsx` (массив плиток около строки 151)
- Факт: утверждение есть, источник под блоком к нему не относится
- Сейчас: «0 переделок на приёмке, если тракт собран по пп. 5.28–5.33 сразу»
- Предложение: убрать плитку или заменить на фразу без гарантии, например что чертёж и состав тракта согласуют до изготовления. Точный текст только после пункта 1 очереди фактов
- Зачем: абсолютная гарантия приёмки
- Усилие: S
- Риск: низкий, если не вписать новую цифру
- Приёмка: на главной нет «0 переделок»; остальные плитки не тронуты, пока не сверены
- Вручную: производство подтверждает формулировку

### 2. «12 → 2» и «+15 %»

- Тот же файл, строки плиток и ссылка на КиберЛенинку
- Факт: ссылка есть, соответствие чисел статье не проверено
- Предложение: оставить только если эксперт подтвердит, что статья говорит это и что перенос на изделия FortInox корректен. Иначе убрать плитки и ссылку вместе
- Усилие: S после сверки, сверка отдельно
- Риск: средний, если оставить чужой опыт как свой результат
- Приёмка: либо есть пометка «по данным статьи, не замер FortInox» после сверки, либо плиток нет
- Вручную: прочитать статью

### 3. Описание «двигатель всасывает»

- URL: карточки зонтов, где длинный `description` из старого магазина
- Файл: `src/data/catalog.json`
- Факт: абзац виден на карточке и не совпадает с комплектом без вентилятора
- Предложение: для этих изделий не выводить старый абзац либо заменить его на уже видимый `short` и таблицу спецификации. Химические цеха и лаборатории не добавлять заново
- Усилие: M, потому что абзац повторяется у нескольких артикулов
- Риск: низкий для SEO, если не менять title, URL и цену
- Приёмка: в HTML карточки нет «двигатель всасывает»; цена, фото, schema те же
- Вручную: выборочно три карточки, пристенная, островная, приточная

## P2, только вместе с фактами

- Отличия барных станций типов 1–5. Без текста от цеха не писать.
- Сверка `/blog/raschet` с `calc.ts`. Отдельная задача инженера, не копирайт.

## Не делать

- Новые посадочные под те же запросы.
- `llms.txt`, отдельные тексты для ботов, смена `robots.ts`.
- Правки Offer, крошек, FAQ-schema и каноникалов.
- Массовая перепись блога.

## После одобрения конкретной строки

Один коммит на строку или на связанную пару. Проверки: `npm run check:schema` не должен сломаться, `npm run build`. Для карточек каталога открыть HTML и убедиться, что абзац исчез, а цена эталона на месте. Деплой только по отдельной просьбе.
